## 📖 About The Project

This project demonstrates modern C# features - **Records** and **Events** - in a practical e-commerce order management system. It showcases how to build loosely-coupled, event-driven applications using ASP.NET Core MVC with clean architecture principles.

### What You'll Learn

-  How to use **C# Records** for immutable data models
-  Implementing **Event-Driven Architecture** in .NET
-  **Publisher-Subscriber Pattern** in practice
-  **Dependency Injection** in ASP.NET Core
-  Building loosely-coupled, maintainable applications
-  MVC best practices with modern C# features

---

## Features

### Core Functionality

-  **Product Management** - Browse and view product catalog
-  **Order Processing** - Place orders with real-time validation
-  **Event Logging** - Automatic logging of all business events
-  **Email Notifications** - Automated customer notifications
-  **Inventory Monitoring** - Low stock alerts and tracking
-  **Audit Trail** - Complete event history tracking
